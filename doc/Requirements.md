| ID | Nome requisito | Descrizione |
| -- | -------------- | ----------- |
| RF-01 | Ricerca prodotto | L'utente deve poter cercare un prodotto specificandone il nome. |
| RF-02 | Filtri | L'utente può specificare parametri aggiuntivi per restringere la ricerca. |
| RF-03 | Prezzo massimo | L'utente può specificare un prezzo massimo entro il quale cercare il prodotto. |
| RF-04 | Ricerca sui siti | Pricey deve cercare il prodotto sui siti configurati. |
| RF-05 | Visualizzazione prezzi | Pricey deve mostrare i siti nei quali il prodotto è disponibile e il relativo prezzo. |
| RF-06 | Monitoraggio | L'utente può selezionare uno o più siti da monitorare. |
| RF-07 | Monitoraggio multi-prodotto | Un utente può monitorare contemporaneamente più prodotti. |
| RF-08 | Notifiche | Pricey deve notificare l'utente quando il prezzo diminuisce almeno della soglia configurata. |
| RF-09 | Soglia | La soglia predefinita è del 5%, ma l'utente può modificarla. |
