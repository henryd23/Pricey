# Product Backlog

## Epic 1 — Ricerca prodotti

### US-01 — Cercare un prodotto

**Come** utente  
**voglio** cercare un prodotto tramite nome o modello  
**così da** poter visualizzare dove è disponibile e a quale prezzo.

#### Acceptance Criteria

- [ ] L'utente può inserire il nome del prodotto.
- [ ] Il sistema avvia la ricerca.
- [ ] Il sistema restituisce i prodotti trovati.
- [ ] Per ogni risultato viene mostrato il sito.
- [ ] Per ogni risultato viene mostrato il prezzo.

**Priorità:** Alta  
**Sprint:** 1  
**Stato:** To Do
